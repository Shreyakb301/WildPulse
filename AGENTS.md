# WildPulse working preferences

Repository: https://github.com/Shreyakb301/WildPulse

- Commit and push completed, verified project milestones to the WildPulse GitHub repository as work progresses. The user explicitly requested ongoing pushes.
- Use commit messages of three or four words, using letters and spaces only. No punctuation, symbols, emojis, or prefixes. Example: `Add wildlife baseline`.
- Follow the README voice and sections used in the user's LoadCheck, RepoLens, and DepotField repositories: plain description, practical features, setup, results or limitations, and engineering record.
- Keep PROJECT_LOG.md local and ignored by Git. Never push it. Keep public PROJECT_NOTES.md current with real results and blockers using Trial headings instead of dates.
- Do not add dates to project documentation. Preserve existing machine-readable seeds and source metadata needed to reproduce verified results.
- Never claim a remote push, file download, test, or log update that has not been verified.
- Do not commit credentials, local environments, downloaded model weights, camera images, or generated runtime bundles by default.

- README detection-preview pictures are authorized. Publish only selected annotated previews for this purpose; original images and runtime bundles remain excluded by default.
